# واجهة Gomaa AI

واجهة شات عربية متجاوبة للمنصة التعليمية، مع ربط مباشر بـ n8n عبر Webhook.

## هيكل المجلد

- `index.html`
- `style.css`
- `script.js`
- `images/logo.png`

## الربط مع n8n

افتح `script.js` وابحث عن:

`N8N_WEBHOOK_URL`

ثم ضع رابط الـ Webhook الخاص بالـ workflow.

الواجهة ترسل POST بصيغة JSON مثل:

```json
{
  "chatInput": "السؤال هنا",
  "sessionId": "معرّف الجلسة",
  "source": "gomaa-ai-frontend"
}
```

لذلك داخل n8n يمكنك قراءة السؤال من:

`{{$json.chatInput}}`

ومعرّف المحادثة من:

`{{$json.sessionId}}`

## شكل الرد

الواجهة تتعرف تلقائيًا على الرد في الحقول الشائعة التالية:

- `output`
- `text`
- `response`
- `answer`
- `message`
- `reply`

ولو كان الرد مصفوفة من عناصر، تحاول الواجهة استخراج أول نص مناسب.

## ملاحظة مهمة

لو كان Webhook الخاص بـ n8n محميًا بالمصادقة أو موجودًا على نطاق مختلف، تأكد من إعدادات CORS والمصادقة في بيئة الاستضافة.

لا تحتاج مكتبة واجهة خارجية؛ الملفات تعمل كواجهة مستقلة.
